# Конфигурация доставки

Файл .design-workflow.json в корне **рабочего проекта** — переносимая договорённость для агента. Клиенты не обязаны автоматически читать его; агент читает его по инструкции web-artifacts. Это не исполняемый adapter и не настройка native plugin manager.

Пример: ../.design-workflow.example.json. Без файла: локальный режим, рекомендуемый каталог artifacts/design. outputDir — относительный путь внутри рабочего проекта; другой путь требует явного выбора пользователя. Не хранить ключи/токены.

artifactMode: local или remote. remote: null либо объект с provider и toolName, указывающий на реально доступный инструмент. Эти строки сами ничего не подключают и не запускают. При remote пользователь должен явно запросить размещение; сначала создаётся локальная копия, затем проверяются инструмент, доступ и конкретное содержимое. Отсутствие сервиса не блокирует локальную работу.

HTML локального режима: inline CSS/classic JS, встроенные данные, SVG/data URL; без fetch, модулей и внешних ресурсов. Storage для file:// не гарантирован: [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage). Для постоянных данных использовать явный JSON export/import. Особенности модулей: [MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules). Справочные CDN-примеры относятся к сетевому opt-in и локальной проверкой отклоняются.
