# UI Kit-first workflow

Scope: portable workflow instructions, source mapping template, package version 0.2.0, GitHub push and native Codex installation. No application migration or automatic public/production writes.

Root cause: G explicitly extracted components after 2–3 screens; R/N allowed a visually consistent canon without executable component ownership. A catalogue could drift independently.

Contract: discovery and owner-selected concepts first; implemented minimal kit before detailed sections in R/N/G; reuse approved libraries; new reusable components enter kit first. Grid/spacing, forms, states and minimal motion are canonical source, not scattered page patches. Verify reuse through consumer rendering and a shared change, not screenshots alone.

Verification: isolated consumer-agent pressure scenarios before/after instructions; package/resources/hash checks; native unittest and portable UI regressions. Runtime verification state must not enter published manifests; source changes must still invalidate hashes.

Release: synchronize manifests/marketplace version, regenerate package fingerprints, verify, simplify scoped diff, commit/push. Use the supported Codex marketplace/plugin CLI and verify cache version/content. Existing unrelated standalone skills remain untouched; new sessions must select the plugin-qualified skill.

Unresolved: none for release scope. Existing application prototype SSOT migration is a separate task.
