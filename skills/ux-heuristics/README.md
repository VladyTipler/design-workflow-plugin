# ux-heuristics

Agent skill for **heuristic UX evaluation**: Nielsen's 10 usability heuristics as the sole scorecard.

For Laws of UX and classic interaction principles, use [`ux-principles`](https://github.com/sanmidable/ux-principles).

## Install

```bash
npx skills add sanmidable/ux-heuristics
```

Pair with principles:

```bash
npx skills add sanmidable/ux-principles
```

Or copy `SKILL.md` and `heuristics.md` into `~/.cursor/skills/ux-heuristics/`.

## What's inside

| File | Role |
| --- | --- |
| `SKILL.md` | Workflow, severity, output format |
| `heuristics.md` | Nielsen's 10 — definitions, probes, common failures |
