# design-system-docs

Portable adaptation of the locally available design documentation skill. It extracts a selected prototype's visual and interaction rules into DESIGN.md from ordinary HTML/CSS, source and screenshots.

No vendor account is needed. Use SKILL.md, templates/DESIGN.md and the fictional examples/DESIGN.md. Upstream provenance and unresolved redistribution rights are recorded in ../../THIRD_PARTY_NOTICES.md.
