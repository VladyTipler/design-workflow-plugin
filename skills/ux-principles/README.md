# ux-principles

Agent skill for **UX principles review**: Laws of UX plus classic interaction principles. Complements [`ux-heuristics`](https://github.com/sanmidable/ux-heuristics) (Nielsen scorecard).

## Install

```bash
npx skills add sanmidable/ux-principles
```

Or copy `SKILL.md`, `laws.md`, and `principles.md` into `~/.cursor/skills/ux-principles/`.

## What's inside

| File | Role |
| --- | --- |
| `SKILL.md` | Workflow, severity, output format, anti-overlap with heuristics |
| `laws.md` | Fitts, Hick, Doherty, Peak-End, Gestalt, … |
| `principles.md` | Progressive disclosure, affordances, mapping, defaults, … |

## Pair with heuristics

```bash
npx skills add sanmidable/ux-heuristics
npx skills add sanmidable/ux-principles
```

- **Heuristics** → usability problems (Nielsen 1–10)  
- **Principles** → cognitive/interaction laws and design principles
