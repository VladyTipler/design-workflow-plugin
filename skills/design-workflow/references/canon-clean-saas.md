# Clean SaaS — необязательный пример визуального канона

Иллюстративный визуальный язык; применять только после выбора пользователем. Это не канон конкретного продукта. Токены и компоненты ниже не означают, что все состояния и контраст уже проверены.

## Токены (CSS-переменные, light/dark)

```css
:root{
 --bg:#f7f8fa;--card:#fff;--border:#e4e7ec;--border2:#d0d5dd;
 --ink:#101828;--ink2:#475467;--ink3:#98a2b3;
 --acc:#5e6ad2;--acc-soft:#eef0fb;--ok:#067647;--ok-soft:#ecfdf3;--ok-brd:#abefc6;
 --warn:#b54708;--warn-soft:#fffaeb;--warn-brd:#fedf89;
 --danger:#b42318;--danger-soft:#fef3f2;--danger-brd:#fecdca;
 --r:10px;--sh:0 1px 2px rgba(16,24,40,.06);--topbg:#fff;
}
html[data-theme=dark]{
 --bg:#101216;--card:#171a21;--border:#272c36;--border2:#39404d;
 --ink:#e8ebf1;--ink2:#aab3c2;--ink3:#77808f;
 --acc:#8b94ec;--acc-soft:#222642;--ok:#3dd68c;--ok-soft:#12271c;--ok-brd:#1e4a35;
 --warn:#f5b544;--warn-soft:#2b2312;--warn-brd:#4a3a14;
 --danger:#ff8177;--danger-soft:#3a1d18;--danger-brd:#5c2a23;
 --sh:0 1px 2px rgba(0,0,0,.45);--topbg:#14171d;
}
```

Правила тем: тёмная — НЕ инверсия, отдельный набор; акцент в тёмной светлеет (#8b94ec) для контраста; первый визит — `prefers-color-scheme`; в standalone file:// выбранную тему хранить в памяти. Постоянное хранение допускается только с проверкой доступности и безопасным fallback.

## Железные CSS-правила (из багфиксов)

- `button{color:inherit}` — иначе нативные кнопки берут UA-чёрный в тёмной теме (прецедент: пресеты регионов).
- `.badge` — `line-height:1; vertical-align:middle; white-space:nowrap; gap:4px` — иначе текст плавает по вертикали.
- Чипы: базовый паддинг `4px 6px 4px 12px` рассчитан на кнопку «×» справа; чип без кнопки — `.chip:not(:has(>button)){padding:4px 12px}`. Одна компонента, 3 состояния: removable / toggle / toggle+description.
- `:focus-visible` кольца всем интерактивам; `prefers-reduced-motion` уважать.
- Один акцент (`--acc`) только на первичных действиях и активных состояниях. Лейблы sentence case, не КАПС. Destructive — изолированная «опасная зона» (только там, где легально для пользователя).

## Компоненты

**Topbar**: logo, топ-нав (активная секция — acc-soft pill), theme-toggle, avatar. Sticky.

**Карточка**: `.card` = card-bg + border + radius 10 + shadow. Заголовок h3 15/600, hint 13 ink3, тело 16px для читаемости на мобильном.

**Чип**: pill с опциональным «×» (кнопка 4px 8px, hover danger-soft). Тоггл-вариант: on = acc-soft + acc + 600.

**Бейдж**: `.badge.ok/.warn/.acc/.mut/.err` — статус-капсы (ГОТОВО / В РАБОТЕ / В ОЧЕРЕДИ / ОШИБКА).

**Сегментированный контрол**: radio-группа, выбранный = card-bg + shadow, переполнение скроллом.

**Switch**: 38×22, checked = acc.

**Undo-тост**: удаление чипа → toast снизу с «Отменить» 4.5 сек + пульс «✓ Сохранено» справа-снизу на change.

**Паттерн ReadyCheck** : чеклист готовности — пункты с круглой иконкой ✓/!, `why`-подпись, ссылка-действие справа ведёт на место исправления; бейдж `4/5`; в кольце — процент. Использовать: настройки (у зависимого переключателя), дашборд, онбординг.

**Паттерн MatchMeter / reveal-метрика**: метрика скрыта за кнопкой-вопросом («Сколько задач подходит?»), по клику раскрывается; демо-цифры помечены бейджем `демо`.

**Паттерн очередь действий**: карточка «Твоё на сегодня» — строки иконка+заголовок+meta+кнопка действия; кнопка убирает строку; пустое состояние «Всё разобрано — очередь пуста» рендерится вместо карточки, когда пусто. Пустой дашборд = хороший дашборд.

**Паттерн inline-связь**: настройка-тумблер, зависящая от данных → слово в лейбле — ссылка на место заполнения (`data-page` роутер); на целевой странице hint «именно их отправляет тумблер на Пульте». Связь в обе стороны.

**Паттерн источник**: данные, порождённые из источника (документ), несут бейдж `← из источника`, статус парсинга (`парсинг OK · дата`) и кнопку «↻ Перегенерировать» с честным перепарсингом. Инцидент-урок: перегенерация без ретрая парсинга давала ложный «успех» с пустым профилем.

**Таймлайн потока** (дашборд): вертикальная линия, точки по статусу (ok/warn/acc/mut), время моноширинным, `why`-строка с тех-причиной (`no-form`, `404`, `service-unavailable`), статус-бейдж справа; старые события — «Показать ранние ▾».

## Структура прототипа-страницы

- Hash-роутинг (`#page`), страницы = `<section class="page">`, нав-подсветка только у `.navlink` (inline-ссылки не ломают её).
- Поиск по настройкам: command-palette (`/` фокус, Esc сброс), результаты со страницей-источником, клик → переход + `.flash` на карточке.
- Сетки: `grid 248px + 1fr` (настройки) / `1fr 280px` (дашборд); внутри карточек `grid2`; на ≤960px — один столбец, рельс в горизонтальный скролл-ряд.
- Сноска в футере каждого артефакта: что реальные данные, что демо-плейсхолдеры; PII маскировано.
